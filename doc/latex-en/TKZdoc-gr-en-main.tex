\nameoffile{\tkznameofpack}
\defoffile{\tkzname{tkz-graph} is a package to draw graphs with \TIKZ\ as
simply as possible: vertices, edges, loops, labels and styles are created
with a few \LATEX\ macros. It belongs to a series of packages whose common
aim is the creation of drawings useful for teaching mathematics. It comes with
the package \tkzname{tkz-berge}, which draws the classic graphs of graph
theory.}
